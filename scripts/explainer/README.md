# Explainer film renderer

This folder is the whole source of `public/media/key404-film.mp4`. There is no
editor project and no timeline file: the Swift code draws every frame as a
function of time, from the research files already in this repository, and
writes the MP4 itself.

## Requirements

- macOS with the Swift toolchain (Xcode or the Command Line Tools). The
  renderer uses CoreGraphics, CoreText, ImageIO and AVFoundation only.
- `npm ci` once. The brand fonts are read from `node_modules`.

## Render

Run everything from the repository root.

```bash
mkdir -p node_modules/.cache/key404-film
swiftc -O -o node_modules/.cache/key404-film/render scripts/explainer/*.swift
./node_modules/.cache/key404-film/render --render
./node_modules/.cache/key404-film/render --poster 3.3
```

`--render` writes `public/media/key404-film.mp4`: 62 seconds, 1920×1080,
24 fps, H.264 with stereo AAC, index at the front of the file, no descriptive
metadata. `--poster 3.3` writes `public/media/key404-film-poster.jpg` from the
frame at 3.3 seconds.

A full render takes about three minutes on an Apple-silicon Mac. Progress is
printed every five seconds. The export stops and reports the writer's state
if nothing moves for 30 seconds, so it cannot hang silently.

## Check

```bash
# Three-second export, to test the encoder before a full render
./node_modules/.cache/key404-film/render --render --seconds 3 --to node_modules/.cache/key404-film/bench.mp4

# Read the finished file back: duration, tracks, bitrate, metadata count, decoded frames
./node_modules/.cache/key404-film/render --inspect public/media/key404-film.mp4 --at 3.3,28.6,50.6

# One frame every two seconds on a single sheet, or chosen frames as PNG
./node_modules/.cache/key404-film/render --contact 2
./node_modules/.cache/key404-film/render --frames 3.3,41.7

# Peak and RMS level of the score in four-second windows
./node_modules/.cache/key404-film/render --score-levels
```

Check output goes to `node_modules/.cache/key404-film`, which is not committed
(`--out <dir>` changes it). Other options: `--no-audio` renders the picture
alone, `--bitrate <bits per second>` sets the video rate (default 3800000),
`--to <file>` sets the output file.

## What it reads

| Input | Used for |
| --- | --- |
| `public/research/sources/pages/73.jpg` to `80.jpg` | the eight source scans |
| `public/research/sources/printed-lines.json` | the 142 body lines; their 6,162 non-space characters are the moving characters |
| `public/research/analysis_outputs/continuation_20261109/numeric_inventory/numeric_inventory.json` | the 24 selected numbers |
| Space Grotesk and IBM Plex Mono in `node_modules/@fontsource*` | all type |

## Files

| File | Holds |
| --- | --- |
| `Support.swift` | frame size, duration, easing, palette |
| `Assets.swift` | fonts, scans, and where each printed character sits on its scan |
| `Draw.swift` | the canvas: type, marker, stamps, tally |
| `Film.swift` | cue times, every scene and all on-screen wording |
| `Audio.swift` | the score, generated from the same cue times |
| `Encode.swift` | stills, contact sheet, MP4 export and read-back |
| `main.swift` | the command line |

## When the wording changes

All on-screen wording and timing is in `Film.swift`. After changing either,
render again and update these by hand so they still match the film:

- `public/media/key404-film.vtt`
- `public/media/key404-film-transcript.txt`
- the written version in `src/components/ExplainerFilm.tsx`

The play button on the site sits in the eye of the key on the 3.3-second
poster. If the poster frame changes, move `.film-play` in
`src/components/ExplainerFilm.css`.

## Notes

- The same source gives the same picture, frame for frame. The encoded bytes
  differ between runs, because the system encoder is not bit-exact and the
  file header carries its creation time.
- The score is generated by `Audio.swift`: sine tones, filtered noise and a
  simple reverb. It uses no recordings or samples. The film reads without it.
- The film shows printed article text only. Do not add key material, seed
  phrases or wallet details as decoration.
