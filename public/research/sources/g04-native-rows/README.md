# Native body-row source views

All 142 native RGB strips and 1,258 canonical whitespace tokens are included, with byte hashes, crop origins and fixed-center rotations in [SOURCE.json](SOURCE.json). The coordinates belong to the original native pass1 crops; later selected OCR views can use different rectangles.

[VISUAL_CLASSES.json](VISUAL_CLASSES.json) contains one qualitative first AI visual pass per row, divided across three assistants. Every token retains its identity and contrast class. These labels do not certify glyph containment or old OCR boxes, and no component ownership is asserted here.

The [source-support report](../../analysis_outputs/continuation_20261110/g04_source_support/RESULT.md) links the exact component atlas, independently accepted two-row masks and separate inverse-field feasibility result. The source model remains incomplete for spacing; no new key decode is claimed. Source and article rights remain with their owners.
