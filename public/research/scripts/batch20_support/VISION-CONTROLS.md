# Vision barcode control provenance

The DataMatrix control PNG and expected text are unmodified ZXing test fixtures, retrieved from the official `zxing/zxing` repository at commit `56b8a9a7b53392097891463023a26c406b422225`. Source: `core/src/test/resources/blackbox/datamatrix-1/0123456789.png` and its `.txt` companion.

Copyright ZXing authors. Apache License2.0; a copy is included as `ZXING-LICENSE.txt`. These are synthetic public decoder controls, never puzzle candidates or queried addresses. QR, Aztec and Code128 controls are generated locally with Apple CoreImage. No external service or code dependency was installed.

Source link: https://github.com/zxing/zxing/tree/56b8a9a7b53392097891463023a26c406b422225/core/src/test/resources/blackbox/datamatrix-1
