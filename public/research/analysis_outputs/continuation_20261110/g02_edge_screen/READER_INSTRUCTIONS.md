# Paper edge marking instructions

Your task is to mark directly visible paper-to-background trim in the registered native-resolution photograph packet. Use only the packet and this instruction sheet. Record your own judgments before seeing any peer marks. Ignore printed content.

Start time is UTC immediately before opening images. Open all eight perimeter windows for each of pages 76–79. Use the four overview images for context as needed. Review the four guide sheets per page to place crossings. Guide sheets show three strips for an edge. Each strip is 49 px wide perpendicular to the marked sampling line's travel, with a red tick outside the pixels at the line to inspect. Ruler labels indicate absolute source pixels. When necessary, read a focused native crop or read the source coordinates by measuring from its pixel origin. Do not treat a drawn ruler, printed border, gutter shadow, sheet stack or image boundary as a trim crossing.

Fill your own copy of the supplied JSON template. Pixel intervals are inclusive and represent the actual uncertainty in the mark. Use a trim label and interval only when a direct visible paper boundary is supported by the surrounding paper surface. Expected trim is head at top, foot at bottom, fore-edge at right for 76 and 78, and at left for 77 and 79. The opposite side is binding and has no eligible trim interval. If a mark falls outside the fixed window, is clipped, or has competing boundaries, use one of binding, adjacent-leaf-shadow, image-crop, obscured or ambiguous with null interval. Note the reason. An approximate observation with no defensible interval is ambiguous.

Allowed interval coordinates for a top crossing are y 0–420, right x 1734–2039, bottom y 2384–2804, and left x 0–305. In an edge record, `runs` lists each directly visible eligible trim segment as an inclusive along-edge [lo,hi] (x for top/bottom, y for left/right). Runs may span windows if you can trace the same visible edge across them. Do not bridge missing or ambiguous sections. A binding side has no eligible trim runs. Set curvature to straight-looking, curved or insufficient, and use a note for glare, curl or confusing boundaries.

Record a visible trim corner only where the head/foot meets the fore-edge inside that corner's window. Use label visible-trim-corner and inclusive box [xmin,ymin,xmax,ymax]. The other corner labels are binding, adjacent-leaf-shadow, image-crop, obscured and ambiguous, each with null box. Do not extend a line to guess a corner. Briefly note what is visible in each of the 32 perimeter windows.

Set completedAtUTC only after all judgments are entered. Report whether prior study outcomes or peer marks were seen. Keep the receipt to the registered labels, coordinates and neutral visual notes. No other repository work is required.
