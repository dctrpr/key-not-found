# Global mirror boundary language audit

Registered before target candidate extraction or checksum validation. [Machine protocol](PROTOCOL.json) freezes all seven source and three implementation hashes, the four formats, exact language conventions, controls and completeness caps. ## Declared language

Concatenate the frozen source row alternatives in this order: 76→77, 77→76, 78→79, 79→78. Keep one mask class (orange/black) and edge (first/last selected word) across all four directed pairs. Four families contain 43,347,744 modeled selection paths. Whole-sequence forward/reverse order and spaced words/joined words/initials yield 24 language descriptions. The theoretical 260,086,464 labeled full readings will **not** be expanded or counted as completed individual checks.

Every possible source token must be nonempty, contain an alphanumeric character and contain no Unicode whitespace. Therefore whitespace-compacted spaced words equal joined words; joined words and initials are already compact. These 24 languages cover the union of exact/compacted forms, although their string sets overlap. Frozen SOURCE_MODEL states/options are schema and first/last-option checked, not recomputed as new geometry. The mask files remain pinned provenance.

## Exact candidate-union method

Each row contributes its finite token/omission alternatives to an acyclic character graph. A boundary state tracks whether a prior word exists, so spaces occur only between actual selected words. Reversing means reversing the entire concatenated row sequence, preserving characters inside each selected word.

The engine gathers every reachable unique WIF/minikey-shaped substring and every boundary-delimited 64hex record. Hex candidates require a coherent path with a nonhex/start boundary before and nonhex/EOF after. A separate lexical-state product matches the shared unfiltered BIP39 tokenizer, including lowercase words, straight/curly apostrophe lookahead, non-dictionary token barriers, invalid-group hard boundaries and EOF. Its last 23 dictionary words preserve every 12/15/18/21/24-word window.

Only future-equivalent graph/lexical states merge. The candidate set therefore matches exhaustive full-string scanning of the modeled language without claiming string or occurrence counts. 846 fixed synthetic comparisons with the common scanner and 1,072 independent exhaustive synthetic comparisons cover joins, omissions, boundaries, long histories and apostrophes. Published-vector validators and explicit cap/lifecycle controls also run before targets.

## Completion and limits

A shared budget allows 2,000,000 product/prefix-state visits and 1,000,000 unique candidate insertions across all 24 languages. Any cap, source/code pin, token invariant, control, extraction or validation failure gives an incomplete/inconclusive result. Partial raw candidates stay private and can be assessed separately; they never justify a complete negative. All 24 descriptors must complete before scopeComplete.

The validators cover WIF, 22/30-character minikey, 64hex scalar and contiguous unfiltered BIP39. No prose hashes, arbitrary ASCII scalars, child-key derivation, address query, wallet import or transaction. A minikey’s 8-bit checksum is weak evidence; any positive needs independent source/witness review. The implementation stores candidate values, not path witnesses.

The geometric guards/rectangles and word-center rule are investigator assumptions. Independent membership choices may be physically inconsistent. A complete zero result excludes only these four declared literal formats from this exact modeled global language at the pinned bytes. It does not calibrate scan errors, prove a creator-selected stencil or exhaust mirror ciphers.

## Reproduce

Python 3.10+ standard library only. From the research archive root, use a new output directory:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/global_mirror_envelope.py --self-test
PYTHONDONTWRITEBYTECODE=1 python3 scripts/global_mirror_envelope.py --run --protocol analysis_outputs/continuation_20261110/mirror_global_envelope/PROTOCOL.json --registration-commit REGISTRATION_COMMIT --out global-mirror-rerun
```

Replace REGISTRATION_COMMIT with the commit first publishing this protocol. Raw candidate values stay in the private output until separately reviewed. A cap failure exits incomplete rather than reporting an exclusion.
